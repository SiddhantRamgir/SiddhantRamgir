## 🚀 What I'm Building

### 🤖 Conversational AI Interview Platform

**Tech:** TypeScript, Node.js, Express, MongoDB, React, LLM APIs

Building a conversational AI interview platform focused on reliable AI workflows and backend architecture.

- Server-controlled interview orchestration and deterministic workflow policies
- MongoDB persistence and structured interview state
- Hands-free voice interaction using voice activity detection and speech recognition
- REST APIs, automated testing, and recovery mechanisms
- Extensible architecture for LLM-driven answer analysis and competency evaluation

### 📈 Market Signal System

**Tech:** Python, Pandas, SQL, Streamlit, Technical Analysis

Developing a financial market analysis and signal-generation system.

- Processing intraday financial time-series data
- Rule-based BUY/SELL/HOLD signals using EMA, RSI, and MACD
- Short-term analysis across 15-minute and 30-minute windows
- Interactive dashboards and visual analytics
- Exploring machine learning approaches for future signal evaluation

### 🏋️ Green Gym | Relabs

**Focus:** Backend Engineering, APIs, Database Integration, GitHub

Contributing to backend development and integration for a fitness application.

- Backend feature development and application fixes
- Frontend-backend integration improvements
- Database and API integration
- Automated testing, code reviews, and merged pull requests

### 🚗 Onbu-AI | Intelligent Carpooling

**Focus:** Entrepreneurship, Data Science, Mobility Technology

Founded Onbu-AI through MTU's student entrepreneurship ecosystem.

- Developed the concept for a data-driven carpooling platform
